# Auto Rename Tabs

Luvus module that names tabs and panes from their current work, ported from herdr-auto-title.

## Language

**Title**:
The auto-computed label for a tab or pane (`N · part › part`).
_Avoid_: name, caption

**Manual title**:
A label the user set by hand; the module never touches it.
_Avoid_: custom name, pinned name, override

**Context pane**:
The single pane a tab's title is derived from.
_Avoid_: active pane, focused pane
